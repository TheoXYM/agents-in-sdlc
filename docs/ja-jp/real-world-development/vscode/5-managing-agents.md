エージェント モードの GitHub Copilot は、コードベースの調査、変更の提案、ファイル編集、コマンド実行を自律的に行います。VS Code の Copilot Chat では、その作業をリアルタイムで確認できます。すべてのツール呼び出しやファイル編集を確認し、差分をインラインでレビューして、変更を個別に採用または却下できます。エディターを離れずに、追加のプロンプトで会話を進め、作業を調整できます。

この演習では、次のことを行います。

- アクセシビリティ エージェントの作業をリアルタイムで監視します。
- 提案されたファイル編集をレビューして採用します。
- セッション中にエージェントへ指示し、ハイコントラスト モードにライト モードを追加します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティ カスタム エージェントは、ハイコントラスト モードを実装中です。作業中にデザイン チームから、既定のテーマが暗すぎると感じるユーザー向けにライト モードも追加してほしいという要望がありました。新しい会話を始めるのではなく、既存のセッションに指示を追加します。

## Copilot の進捗を監視する

Copilot Chat ビューには、エージェントが調べたファイル、実行したコマンド、提案した編集が順番に表示されます。各ファイルの編集は差分と **Keep** / **Undo** の操作とともにチャット内に表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、ツール呼び出しを確認します。ファイルの読み込みや編集、実行を求められたターミナル コマンドが表示されます。
3. エージェントが編集を提案したら、差分を確認します。
   - **Keep** を選択すると変更を採用します。
   - **Undo** を選択すると変更を元に戻し、エージェントに再度作業させます。
4. チャット上部の **Files changed** を開き、セッション中に変更されたファイル全体を確認することもできます。

> [!NOTE]
> ターミナル コマンドの実行などに許可が必要な場合、エージェントは一時停止して **Allow** を表示します。内容を確認し、許可してよいコマンドだけ承認してください。

5. エージェントがハイコントラスト モードを実装し終えるまで待ちます。最後に変更の概要が表示されます。

## ライト モードを追加するようエージェントに指示する

ハイコントラスト モードができたら、同じ会話でライト モード切り替え機能を追加します。会話を続けることで、エージェントは編集したコンポーネント、スタイル、local storage を使った設定の保存方法など、これまでのコンテキストを引き継ぎます。

1. Copilot Chat の入力欄に次の追加プロンプトを送ります。

   ```plaintext
   Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
   ```

2. エージェントは既存の変更を調べ、ライト モードの追加を提案します。
3. 各差分を確認し、ハイコントラスト モードと同じように **Keep** または **Undo** を選択します。
4. エージェントの方向性が希望と異なる場合 (たとえば、切り替え UI のリファクタリングが好みでない場合) は、チャット入力欄の横にある **Stop** で停止し、追加の指示を送ります。

> [!TIP]
> 進行中のセッションを調整すると、最初からやり直すより速く作業できます。「CSS を簡潔にし、セレクターの重複ではなく CSS 変数を使う」のような修正、「3 つ目のトグルを追加せず、既存の設定パネルにライト モードを加える」のような方向修正、「両方の切り替えにキーボード ショートカットを追加する」のような範囲の拡張を、追加プロンプトで依頼できます。

## 変更されたファイルをレビューする

変更をコミットする前に、エージェントが編集した内容を確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが含まれます。
3. いくつかのファイルを開いて差分を確認します。アクセシビリティ エージェントの指示どおり、ARIA 属性、キーボード操作、セマンティック HTML、local storage による設定の保存が実装されていることを確認します。
4. 問題がなければ **Source Control** パネルから変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェント モードで進行中のセッションを監視して調整し、ファイル編集ごとにレビュー、採用、却下し、コンテキストを失わずに作業を拡張しました。

この演習では、エージェントの作業をリアルタイムで監視する方法、個別のファイル編集を採用または却下する方法、追加プロンプトでセッション中に指示を出す方法を学びました。
