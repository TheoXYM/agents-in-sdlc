Explora GitHub Copilot durante todo el ciclo de vida del desarrollo de software con escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar su comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres una nueva persona desarrolladora en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El backlog del equipo ya está registrado como incidencias de GitHub, listas para que las elijas. Incluye trabajo de funcionalidades, como filtros y paginación, además de mejoras de calidad, como accesibilidad y estándares de programación.

## Elige tu entorno

GitHub Copilot te acompaña en el entorno donde trabajes. Elige el que mejor se adapte a tu forma de desarrollar. Cada taller empieza con sus propios pasos de configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente de agentes desde el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades de agente, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia de modo de sesión, colabora en canvases y gestiona incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [Agente en la nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa su progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
